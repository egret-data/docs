# Backlog: dashboards

Findings from documenting Explore → Dashboards (2026-10-19, demo instance, product source in `egret-docs-run`). Recorded, not fixed.

| Area | Type | Sev | Description | Evidence (page/URL/steps) |
|---|---|---|---|---|
| dashboards / edit | Bug | S1 | A space or Enter typed into a heading or text card in edit mode is not inserted. The card wrapper (`role="button"`) handles Enter and Space with `preventDefault` and the keydown bubbles up from the input/textarea, so "Weekly sales review" becomes "Weeklysalesreview" and a two-line text becomes one word. Paste works. | Dashboard → Edit → text or heading menu → type "a b". Source: `DashboardView.tsx` dashcard-body `onKeyDown`. |
| dashboards / filters | Bug | S1 | A value chosen in a `date` / `all-options` filter is lost. The picker emits an object, the URL stores it as JSON, and `useDashboardParams` reads it back as a plain string (only arrays and `between`/`range` are parsed), so the chip shows no value and the cards are not filtered. Only the editor's default works. | Sales performance on a dashboard with an all-options date filter: open the chip → Specific → After 1997-06-01; chip stays "Order date", reload does not restore it. |
| dashboards / filters | Bug | S2 | A filter that has a default value cannot be cleared by a viewer: the chip's X removes the URL parameter, then the default is applied again. "Reset all filters" is offered only when the URL has a parameter, so defaults never count. | Sales performance → X on "Order date: 1995-01-01 – 1996-12-31" → chip returns. |
| dashboards / filters | Gap | S2 | The editor can only connect a filter to a chart's own dimensions and plain columns (`columnsForParam`). Single-number (scalar), gauge and other metric-only cards offer "This card doesn't have any fields that can be mapped", and a time-series cannot be filtered by a column that is not one of its dimensions. The server accepts such mappings (API-created ones work). The column list is also not narrowed by filter type. | Edit Sales performance → select a filter → KPI cards show the "no fields" message. |
| dashboards / cards | Bug | S3 | Text and heading cards print `[object Object]` for a `{{slug}}` bound to an all-options date filter (`interpolateParams` stringifies the object). | Add `{{order_date}}` to a text card on a dashboard whose date filter is all-options. |
| dashboards / cards | UX | S3 | The card **Title** box says "Blank = chart name", but after typing and clearing it the card stores `title: ""`, which hides the caption, the description icon and the title link. | Edit → click a chart card → type "x" in Title, clear it → caption disappears. |
| dashboards / filters | UX | S3 | A filter's slug (used in URLs and `{{slug}}`) is assigned once as `filter`, `filter_2`, … and is neither shown nor editable; renaming the filter does not change it. | Add three filters and rename them; URL parameters stay `filter`, `filter_2`, `filter_3`. |
| dashboards / filters | UX | S3 | The **Search box** widget option has no effect: `FilterControl` renders the same list with a search input for Dropdown and Search box. | Filter settings → How should people filter on this? |
| dashboards / filters | UX | S3 | The Type select shows internal names (`text`, `temporal_unit`, …) rather than labels such as "Time grouping". | Filter settings → Type. |
| dashboards / edit | UX | S3 | Selecting a card, filter or "Add cards" opens a 340 px side panel. On a fixed-width (1048 px) dashboard the canvas then falls under 753 px, so the grid flips to the one-column mobile layout and cards cannot be moved or resized until the panel is closed. A drag also ends with a click that opens the panel. | Edit "Executive summary" → click a card; cards stack. |
| dashboards / interactivity | Bug | S3 | The drill menu is positioned at the pointer without clamping to the viewport, so on a card at the right edge it is cut off. | Sales performance → click a bar in "Top 10 clerks". |
| dashboards / interactivity | Gap | S3 | "See these records" ignores the dashboard filters and shows the first 1000 rows of the whole dataset for the clicked value. | Sales performance → click a pie slice → See these records (rows from 1992 shown while the date filter is 1995-1996). |
| dashboards / interactivity | Gap | S3 | Custom URL clicks insert `{{value}}`, `{{column}}` and `{{slug}}` without URL encoding. | `resolveClick` / `interpolateUrl`. |
| dashboards / export | Bug | S3 | The download popover promises "The maximum download size is 1 million rows", but the file is built in the browser from the rows the card loaded, which a chart caps at 10,000 (`MAX_CHART_ROWS`). | Card → download. |
| dashboards / export | Gap | S3 | The rendered print page (`/embed/print`) used for PNG/PDF reports draws chart cards only, with the chart's name and settings: card title and visualization overrides, text, heading and link cards, and tabs are ignored. | `PrintObject.tsx`, `render/payload.rs` `build_dashboard`. |
| dashboards / list | UX | S3 | The Trash view still shows the **+ Dashboard** button and the folder count in the summary line. | Dashboards → Trash. |
| dashboards / list | UX | S3 | Deleting a folder, moving a dashboard to Trash and reverting a revision happen without confirmation. Deleting a folder moves its dashboards to Uncategorized. | Folder ⋯ → Delete; row ⋯ → Move to Trash; History → Revert. |
| dashboards / list | Gap | S3 | The folder API accepts a blank name (`POST /folders/dashboards {"name":"  "}` returns 200) and names are unique only case-sensitively (`Finance` vs `finance`), while the UI trims and refuses blank names and the bulk move treats names case-insensitively. | API call above. |
| dashboards / page | Gap | S3 | "Subscribe…" exists only in the list row menu; the dashboard page's ⋯ menu has no subscribe item. There is no dashboard-level cache setting, public link or embed option. | Dashboard page ⋯ menu. |
| dashboards / filters | Gap | S3 | Limiting a filter's choices ("Limit this filter's choices") could not be verified end to end on the demo data (every priority exists for every status). Not a defect, a verification gap. | Filter settings panel. |
