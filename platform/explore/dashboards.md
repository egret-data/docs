# Dashboards

A dashboard arranges charts on a grid.

![A dashboard](/img/platform/explore-dashboard-view.png)

Open a dashboard from the list. The header has a **favorite** star, **history**, **Fullscreen**, **info** and a **⋯** menu, and **Edit** to change the layout. Each card has an edit shortcut (opens its chart) and a download action.

## Edit a dashboard

Press **Edit** to change the layout. Cards sit on a 24-column grid; a card's position and size are measured in grid units.
