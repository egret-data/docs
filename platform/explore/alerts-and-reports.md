# Alerts & reports

An **alert** runs SQL on a schedule and notifies you when the result meets a condition. The **Reports** tab lists scheduled reports.

![Alerts & Reports](/img/platform/explore-alerts.png)

The page has two tabs, **Alerts** and **Reports**. Use **+ Alert** to create an alert on SQL, or **+ Data API alert** to alert on a [Data API endpoint](../data-api/overview).
