# Executions

An execution appears each time a flow runs: from its **Run** button, a schedule, a webhook or another flow.

![Executions](/img/platform/workflows-executions.png)

Filter by **State**, **Namespace**, **Flow** and **Time**, and toggle **Show child executions**. The header counts executions by state.

## An execution

Open an execution to see tabs for **Overview**, **Topology**, **Gantt**, **Logs** and **Outputs**. **Replay** re-runs a finished execution; **Kill** stops one that is running.

![Execution logs](/img/platform/workflows-execution-logs.png)

The **Logs** tab groups log lines by task and can be filtered by level, task and task run, and downloaded.
