# Overview

Egret is an enterprise data platform that lets many teams work on one unified data foundation.
One deployment gives the organization a single source of truth, each team an isolated
**workspace**, and every access to data is **governed and audited**.

Egret is written in Rust as a modular monolith and consolidates BI and exploration, an Iceberg REST
catalog, access policy, a data API builder and workflow automation behind one shared design system.
