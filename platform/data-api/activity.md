# Activity

**Activity** shows the calls made to this workspace's endpoints.

![Activity](/img/platform/data-api-activity.png)

Choose a range with **1h**, **24h**, **7d** or **30d**; call data is kept for 90 days. **Include trial runs** also counts calls made from the endpoint editor's try-it panel, which are excluded by default.
